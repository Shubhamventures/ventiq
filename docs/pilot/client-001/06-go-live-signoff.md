## 8. Pilot review cadence

During the controlled pilot, record:

- material defects;
- recurring manual friction;
- client feature requests;
- workflows abandoned outside VENTIQ;
- workflows completed successfully in VENTIQ;
- user/access changes;
- migration corrections;
- investor-facing issues;
- evidence that supports or rejects broader rollout.

The purpose of the first pilot is not to maximize feature count. It is to prove repeatable fund operation and identify the smallest set of improvements required for the next client.
